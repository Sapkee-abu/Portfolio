Project concept

Weather data is often presented as numbers and charts that users need to interpret. Dee uses Open-Meteo forecast data as context to explain the weather and offer guidance, such as how to prepare before leaving home or when to plan an activity.

The app sends the user's question and selected coordinates to the backend, which prepares Open-Meteo weather data and relevant chat history for the LLM. The response appears in chat, while the weather screen and charts display API data directly.

My contribution

  1. 01

    Developed the Android app with React Native, Expo, and TypeScript, including weather, chat, locations, and settings screens.

  2. 02

    Built a Python and FastAPI backend to retrieve and prepare current, hourly, and daily weather data for the user's coordinates.

  3. 03

    Integrated the Gemini API using weather data, conversation history, and the user's selected reply as context.

  4. 04

    Designed prompts for a friendly assistant that distinguishes current conditions from forecasts and answers using the supplied information.

  5. 05

    Designed primary and fallback model ordering and supported local AI through Ollama.

  6. 06

    Built charts for temperature, humidity, rain, wind, and UV, with a theme that changes according to the current hour's weather.

Result

An Android app that brings weather forecasts and AI chat together, with an APK available to download and install.
